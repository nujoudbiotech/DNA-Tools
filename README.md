# DNA-Tools | Cell & Gene Therapy Toolkit 🧬

My first bioinformatics toolkit focused on **Cell & Gene Therapy**

### 🔬 What it does:
- **CRISPR Gene Editing:** Design guide RNA (gRNA) for gene editing
- **mRNA Therapeutics:** Analyze & design mRNA sequences for therapy  
- **DNA Analysis:** FASTA Parser, Protein Translation, GC content, reverse complement

### 🛠️ Built With:
Python | Biopython
